<p align="center">
  <img src=".github/logo.png" alt="ping logo" width="128" />
</p>

A small VB.NET Windows Forms ping tool.

## What it does

Enter a host (it defaults to `192.168.10.1`) and click the button. It pings the
host with `System.Net.NetworkInformation.Ping` and shows each reply, timeout or
unreachable result.

## Tech

- Visual Basic .NET (Windows Forms)

## Building

Open the `.sln` file in Visual Studio and build it. Windows only.
